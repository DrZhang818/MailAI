# 学习阶段 1：文件操作、进程竞争与文件锁

## Goal

掌握 Unix 文件操作和进程互斥的基础，能够独立推演文件描述符、读写偏移量和锁的生命周期，解释两个 MailAI 进程操作同一数据目录时为什么需要协调。

阶段结束时，学习者应能在不参考实现的情况下说明数据目录锁的行为，再对照 `DataDirLock` 解释其打开、争锁、等待、报错和释放路径。学习范围覆盖文件操作、必要的进程知识、竞争条件和 `flock`，不扩展为完整的文件系统、线程同步或内核实现课程。

## Architecture

学习按“文件引用模型 → 文件操作与失败处理 → 进程交错执行 → 文件锁 → 资源生命周期 → MailAI 综合分析”的顺序展开。前面的实验建立后面推演所需的模型，最后用同一套模型解释项目中的数据目录锁。

文件引用模型区分路径、进程文件描述符表、内核中的打开状态和底层文件身份。并发模型区分进程私有状态与共享资源，通过保持各进程内部顺序的交错执行分析竞争。资源模型同时追踪 C++ 对象的所有权与内核引用的存续，避免用对象析构代替完整的释放条件分析。

导师负责提出问题、讲解模型、准备实验和核对证据。学习者负责先描述自己的理解、预测实验结果，并在讲解后完成独立推演。算法类比用于帮助建立模型，随后明确类比的边界。每个任务都以一次独立解释和实验核对作为交付结果。

学习实验在 macOS 本机的隔离临时目录中使用虚构数据执行。涉及临时源码和编译产物时，通过全局约定的 `codex-cleanup run` 管理。项目阅读围绕已有的 `include/mailai/data_dir_lock.h`、`src/store/data_dir_lock.cpp` 和相应测试展开。业务约束引用[阶段 2 计划](../../phase-02-mail-sync/plan.md)的 S-10、AC-4 和 Task 2 第 14 步。

## Spec

- **S-1：先思考再验证。** 每个任务先说明目标、实验输入、需要观察的输出和限制，再让学习者表达理解或预测。导师点评后讲解并提供必要示例，最后用变式检验理解。不能把看过参考代码或编译成功记为独立掌握。
- **S-2：准确建立文件操作模型。** 区分路径、fd、打开状态和文件身份。说明访问模式、创建标志、权限、偏移量和实际读写字节数。系统调用失败时依据其返回值读取并及时保存 errno，重试规则按照具体接口和目标平台分别判断。
- **S-3：用执行顺序分析竞争。** 区分进程私有内存与共享文件。竞争分析必须列出保持各进程内部顺序的具体交错过程，指出需要共同保护的操作。并发实验使用明确的就绪信号或控制机制安排顺序，不能只靠随机运行和固定 sleep 判断正确性。
- **S-4：明确文件锁的契约。** 解释共享锁、独占锁、阻塞和非阻塞申请，以及协作式锁的边界。目录锁通过约定争用固定文件协调业务，不自动限制目录内的所有文件操作。必须分析同名文件删除重建后锁对象可能改变的情形。
- **S-5：追踪实际持有的资源。** 区分整数复制、dup、独立 open 和 fork 继承。解释 close、显式解锁、对象移动、成功 exec 和进程退出对资源的影响。不能在仍有相关引用时笼统断言关闭一个 fd 或结束一个进程必然释放锁，也不能把 O_CLOEXEC 理解成禁止 fork 继承。
- **S-6：按项目契约完成综合分析。** 数据目录锁接收目录和非负等待时长，成功时交付持锁对象，失败时区分参数错误、锁忙和其他存储错误。默认等待预算为 5 秒，等待为 0 时仍尝试申请一次。分析提前返回、超时和移动后的释放责任，保留已有锁文件及其内容，并区分目录锁与短 SQLite 写事务的职责。只读缓存查询不取得目录写锁。
- **S-7：限定环境与验收范围。** 实验使用 macOS 本机 C++23；接口细节以本机手册为依据，涉及其他系统时明确平台差异。只在隔离目录操作虚构文件，不访问真实邮件或凭据。业务源码只有在用户明确委托后才由导师修改。课程验收证明学习目标，项目功能验收另按既有阶段计划执行。

## 验收条件

- **AC-1：文件引用模型。** 学习者能够画出两个进程的 fd 表与底层文件的引用关系，解释相同 fd 数字为什么不能证明文件相同。实验中能够识别关闭后编号复用，区分合法的 fd 0 与打开失败的 -1。
- **AC-2：打开方式与权限。** 学习者能够解释项目打开锁文件时各参数的作用，并预测创建、截断和追加对已有内容的影响。实验核对内容和权限，学习者能够说明创建权限受 umask 影响且不会自动修改已有文件权限。
- **AC-3：读写与偏移量。** 学习者能够预测分次读取、改变偏移量和两次独立打开后的结果，并通过实际读取核对。能够在部分写入后失败的场景中指出已发生的副作用，区分 EOF、调用失败和未完成全部请求。
- **AC-4：错误处理与清理。** 学习者能够根据指定接口的返回值判断何时读取 errno，解释为什么要及时保存错误码。对打开失败、打开后后续失败和中断分别给出处理理由，并指出哪些路径需要关闭已有 fd。
- **AC-5：进程与共享资源。** 学习者能够根据 PID、变量和文件访问的实验结果，区分进程私有状态与共享文件，解释普通全局变量和各进程单独创建的普通 mutex 为什么不能直接协调两个独立实例。能够用交错执行说明单核也会出现并发问题。
- **AC-6：竞争与临界区。** 学习者能够独立列出一次丢失更新和一次检查后操作出错的交错顺序，标明必须共同保护的操作。受控实验复现对应结果，并能够说明原子创建解决的窗口及异常退出后仍需处理的标记问题。
- **AC-7：争锁行为。** 学习者能够预测两个进程申请共享锁或独占锁时的兼容关系，解释非阻塞冲突与阻塞等待的区别。实验核对同一文件上的争锁结果，并验证不同目录中的锁文件可以独立持锁。
- **AC-8：文件身份与锁失效。** 学习者能够在删除重建场景中画出旧、新文件及各自持有者的引用关系，解释同名路径为什么可能失去互斥效果。实验核对文件身份和申请结果，能够说明锁文件存在与实际持锁状态的区别。
- **AC-9：资源生命周期。** 学习者能够预测作用域结束、移动、dup 后关闭、fork 继承和进程退出后的持锁状态，并用实验核对。能够解释正常析构与内核清理的区别，以及 O_CLOEXEC 生效的时机。
- **AC-10：完整组件分析。** 学习者能够先独立描述目录锁的状态转换，再逐条解释当前实现的主要成功和失败路径。综合实验核对立即取得、立即冲突、等待后取得、到期报忙、退出后恢复和已有内容保留。能够解释只读查询与 SQLite 事务为什么遵守各自的边界。

## Tasks

### Task 1：建立路径、文件与 fd 的引用模型

目标：交付一份能够解释跨进程编号与文件关系的引用图。

步骤：

1. 导师提出两个独立进程都打印相同 fd 的场景，说明需要判断的文件关系，由学习者先给出理由。
2. 导师讲解路径、fd 表项、打开状态和底层文件之间的关系，学习者据此修正引用图。
3. 学习者预测打开、关闭和重新打开临时文件时编号可能发生的变化，说明哪些结果由接口保证。
4. 导师运行对应实验，核对编号复用以及标准描述符关闭后 fd 0 可以合法取得的行为。
5. 学习者分析一个 fd 数字相同但文件不同的变式，独立说明 fd 为什么不是内存地址。

验收：AC-1。核对引用图、实验观察和变式解释是否一致。

### Task 2：理解文件打开方式与创建权限

目标：交付对一次完整 open 操作的参数解释和副作用预测。

依赖：Task 1。

步骤：

1. 导师给出保留已有内容和按需创建文件的需求，由学习者先说明需要向系统表达哪些要求。
2. 导师讲解全局作用域写法、访问模式和相容标志的组合，明确创建、截断、追加和排他创建的区别。
3. 导师讲解八进制权限和 umask，学习者预测新建文件与已有文件的权限行为。
4. 导师运行不同打开方式的实验，核对已有内容是否被保留、截断或追加，并检查新文件权限。
5. 学习者解释项目中的打开参数，指出 O_NOFOLLOW 和 O_CLOEXEC 分别约束哪一类行为。

验收：AC-2。参数解释与内容、权限的实际观察相符。

### Task 3：推演文件读写和偏移量变化

目标：交付一份能够逐次说明读写内容、返回数量和偏移量的推演。

依赖：Task 2。

步骤：

1. 导师给出固定内容文件的分次读写操作，由学习者先预测每次返回的字节数和内容。
2. 导师讲解 read、write 和 lseek，说明请求数量、实际完成数量和打开状态中的偏移量。
3. 学习者比较两次独立 open 与通过 dup 取得另一个 fd 的读取过程，分别给出预测。
4. 导师运行偏移量实验，核对各次读取和重定位后的结果。
5. 导师给出部分读写的返回序列，学习者说明后续应该继续处理的字节范围和已经发生的修改。
6. 学习者用变式区分普通文件 EOF、调用失败、全部写完与持久化保证。

验收：AC-3。逐次推演与实验相符，部分操作的副作用解释完整。

### Task 4：形成系统调用错误处理方案

目标：交付能够区分失败原因、保存诊断并清理资源的处理流程。

依赖：Task 3。

步骤：

1. 导师给出打开失败和打开后后续失败的场景，由学习者先指出各路径已经持有什么资源。
2. 导师讲解返回值与 errno 的关系，学习者确定读取和保存错误码的位置。
3. 导师运行路径不存在与无效描述符的实验，核对错误来源及调用后的资源状态。
4. 导师结合本机手册讲解 EINTR，分别核对 open、read、flock 和 close 的处理前提。
5. 学习者为指定失败路径提出重试、返回错误和释放资源的方案，并解释每项决定。

验收：AC-4。错误判断、保存时机和清理责任均有明确依据。

### Task 5：区分进程私有状态与共享资源

目标：交付对两个程序实例的资源划分和执行顺序分析。

依赖：Task 4。

步骤：

1. 导师提出两个终端运行同一个程序的场景，由学习者先划分变量、fd 表和文件的共享关系。
2. 导师讲解进程、PID、地址空间和调度，学习者修正资源划分。
3. 导师演示独立进程访问私有变量与同一文件的实验，核对 PID 和状态变化。
4. 导师说明后续实验需要的 fork、waitpid 和 exec 的职责，学习者区分创建进程与替换程序。
5. 学习者用单核交错顺序解释竞争的可能性，并说明为什么各进程各放一个普通 bool 或 mutex 不足以协调。

验收：AC-5。资源划分正确，能够把实验观察转化为执行顺序解释。

### Task 6：构造竞争条件并确定临界区

目标：交付能够稳定复现错误的交错顺序和应受保护的操作范围。

依赖：Task 5。

步骤：

1. 导师提出两个进程更新文件计数的需求，由学习者先构造可能丢失更新的执行顺序。
2. 导师点评该顺序，讲解竞争条件、临界区和特定操作的原子保证。
3. 导师用明确的进程间信号控制读写顺序，运行实验并核对丢失更新。
4. 学习者分析先检查文件不存在再创建的方案，指出检查结果何时可能失效。
5. 导师演示排他创建的行为，学习者说明它消除的竞争窗口及进程异常退出后标记残留的影响。
6. 学习者调整保护范围，解释为什么只保护最后一次写入仍可能遗漏关键步骤。

验收：AC-6。交错顺序可复现，临界区覆盖产生错误的全部相关操作。

### Task 7：掌握 flock 的申请与等待契约

目标：交付对两个进程争锁结果和继续执行条件的准确预测。

依赖：Task 6。

步骤：

1. 导师提出只允许一个进程进入受保护操作的需求，由学习者先说明申请成功和失败时应怎样继续。
2. 导师讲解共享锁、独占锁、显式解锁和非阻塞选项，学习者推演各类申请的兼容关系。
3. 导师运行同一锁文件上的两个进程实验，分别核对立即冲突和阻塞等待后的行为。
4. 导师比较不同目录中的锁文件，验证独立文件上的锁不会形成同一组竞争。
5. 学习者解释协作式锁的前提，说明其他进程绕过锁协议时为什么仍可能修改文件。
6. 学习者把固定锁文件与 MailAI 的数据目录保护范围对应起来，解释只读命令的约定。

验收：AC-7。兼容关系、失败结果和受保护范围的解释均与实验相符。

### Task 8：解释删除重建造成的锁对象变化

目标：交付对同名锁文件失去互斥效果的引用关系分析。

依赖：Task 7。

步骤：

1. 导师提出释放后删除锁文件的方案，由学习者先判断它在多个进程之间是否始终可靠。
2. 导师讲解目录项、unlink 和已打开引用的关系，说明设备号与 inode 号的观察用途。
3. 学习者推演旧文件仍被引用而同名文件被重新创建的过程，画出各进程指向的文件。
4. 导师在隔离目录中运行删除重建实验，核对文件身份和各自申请锁的结果。
5. 学习者根据结果修正方案，解释为什么锁文件应保留，以及为什么不能用文件是否存在判断占用。

验收：AC-8。引用图能解释互斥失效，并给出保持共同锁对象的理由。

### Task 9：追踪对象、fd 与锁的生命周期

目标：交付覆盖正常返回和进程退出的资源所有权分析。

依赖：Task 8。

步骤：

1. 导师给出整数复制、dup、独立 open 和 fork 的场景，由学习者先预测各自增加了什么引用。
2. 导师讲解相关引用与锁释放的关系，学习者标出关闭一个 fd 后仍可能存续的持有者。
3. 学习者提出用 C++ 对象管理 fd 的方案，导师据此讲解 RAII、禁止复制和移动后失效状态。
4. 导师运行作用域结束、移动和 dup 后关闭的实验，核对释放责任与持锁状态。
5. 导师运行 fork 继承和进程退出的实验，核对仍有其他相关引用时锁的存续。
6. 导师结合成功 exec 的实验解释 O_CLOEXEC，学习者区分它与 fork 继承的关系。
7. 学习者分析未执行 C++ 析构的退出场景，说明内核清理为什么仍然发生，以及结论受到哪些引用关系限制。

验收：AC-9。每个场景都能指出仍存续的引用和实际释放条件。

### Task 10：独立分析并验证 DataDirLock 的完整行为

目标：交付一份覆盖正常使用、争用和失败恢复的数据目录锁说明。

依赖：Task 9。

步骤：

1. 导师重述项目的目录锁需求、输入输出和限制，由学习者先独立描述打开、申请、等待、失败和释放的状态转换。
2. 导师点评状态转换，学习者对照头文件解释有效对象、无效对象和所有权转移的约束。
3. 学习者阅读 acquire，逐条解释输入检查、打开文件、保存错误和提前返回时的清理责任。
4. 学习者推演非阻塞重试、等待间隔和 steady_clock 的用途，说明等待预算与实际调度延迟的区别。
5. 导师运行立即取得、立即冲突、等待后取得和到期报忙的综合实验，核对结果及错误分类。
6. 导师验证释放后重新取得、进程退出后的恢复和已有文件内容保留，学习者用引用模型解释结果。
7. 学习者结合阶段 2 规格说明目录锁覆盖的业务范围，区分它与不跨网络请求的 SQLite 短写事务，并解释只读缓存查询的路径。
8. 导师给出一个未见过的失败或继承场景，学习者先独立预测，再核对实际行为，完成本阶段综合验收。

验收：AC-10，并复核 AC-1 至 AC-9。综合说明能从文件模型解释到业务行为，实验结论有实际运行依据。
