# 学习阶段 1 进度

对应[阶段计划](plan.md)。按用户要求，每轮完整讲解一个 Task，优先使用已有的算法和 C++ 知识作类比，由用户按需追问。练习由用户亲自编写和运行，导师提供说明、必要骨架并核对实际代码与输出。正式计划保持冻结。

| 任务 | 状态 | 验证证据 |
|---|---|---|
| Task 1：路径、文件与 fd | 整课讲解后，用户反馈已理解 | macOS 本机使用 clang++、C++23 和严格警告选项编译临时示例，编译与两次独立进程运行均成功。同一进程两次打开同一文件得到 fd 3 和 4；关闭 3 后打开另一文件复用 3；关闭标准输入后 open 返回合法的 fd 0；不存在的路径返回 -1。两个独立进程首次打开不同文件都得到 3，读取内容分别对应各自的文件。 |
| Task 2：打开方式与创建权限 | 导师实验已验证，配合整课讲解 | macOS 本机 C++23 临时示例编译、运行和结果检查均成功。验证创建标志保留已有内容和权限、截断在打开时发生、普通写入覆盖与追加写入的区别、排他创建返回 EEXIST，以及 umask 0022 下请求 0666 和 0600 分别得到 0644 和 0600。末尾符号链接配合 O_NOFOLLOW 返回 ELOOP；O_CLOEXEC 设置了 FD_CLOEXEC 标志。 |
| Task 3：读写与偏移量 | 用户完成并运行分段写入练习；其他内容已讲解及导师演示 | 用户在 `docs/lock-learn/write_practice.cpp` 补齐源地址、剩余数量和累计进度，执行 `clang++ -std=c++23 -Wall -Wextra write_practice.cpp -o write_practice` 与 `./write_practice`；截图显示每次完成 3、3、3、1 字节，累计 3、6、9、10。导师此前的独立实验另覆盖分次读取、短读与 EOF、定位、独立 open 与 dup、读写共用偏移量、末尾之外写入和二进制缓冲区，不记为用户已经完成的练习。 |
| Task 4：错误处理与清理 | 用户已运行两类失败分支；errno 与 perror 已补充讲解 | 用户编译 `error_practice.cpp` 并分别运行 `./error_practice` 和 `./error_practice write-demo.txt`。截图先显示 open 失败、保存值 2 且等于 ENOENT，后显示 write 失败、保存值 9 且等于 EBADF。源码在写入失败后先保存 errno，再关闭已取得的 fd。另用简化变量模型解释 errno 的存储作用；故意覆盖 errno 的扩展实验没有用户运行证据，不记为完成。 |
| Task 5：进程与共享资源 | 用户已运行父子进程与私有变量实验 | 用户编译并运行 `process_practice.cpp`。截图中父子 PID 相互对应，子进程修改后 value 为 20，父进程仍为 10，打印的变量虚拟地址相同；源码使用 waitpid 等待子进程。共享文件的用户实验并入 Task 6 的受控计数场景核对。 |
| Task 6：竞争条件与临界区 | 导师受控实验已验证，待用户练习与反馈 | 在受管理临时目录编译用户的 `race_practice.cpp`，通过输入管道依次放行两个进程。双方先读到 0，再分别写回 1，最终为 1；顺序执行时最终为 2。另验证两个进程先检查不存在再普通创建会同时成功，使用 O_CREAT 与 O_EXCL 时仅一个成功，另一个得到 EEXIST；创建者退出后标记文件仍保留。以上为导师实验，不记为用户已运行或掌握。 |

实验通过只证明演示行为，用户理解情况按其实际反馈记录，不据此推定已经独立通过所有验收。后续通过用户的解释或问题核对理解，不额外强制设置问答关卡。
